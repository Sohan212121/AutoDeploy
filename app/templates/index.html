Automated Deployment Flow

6-Step Pipeline

Every commit triggers an automated pipeline designed for reliability, fast feedback, and safe rollback if a release fails.

  1. 1

    Push

    Developer commits code and pushes branch to GitHub, triggering webhook events.

  2. 2

    Test

    CI runner launches isolated test runner, executing automated pytest suites and lint checks.

  3. 3

    Build Image

    Multi-stage Docker container image is built, embedding immutable commit metadata and tags.

  4. 4

    Push to Registry

    Validated production container image is signed and uploaded to the remote container registry.

  5. 5

    Deploy to Local Host

    A self-hosted GitHub Actions runner on the developer's Windows PC pulls the verified image and replaces the container in Docker Desktop, with a short gap while the container restarts.

  6. 6

    Health Check

    Automated probes verify the /health and /version endpoints before marking rollout complete.

Available Service Endpoints

GET / Web dashboard displaying system metadata & deployment status
GET /health Liveness & readiness check returning JSON status and version
GET /version Machine-readable JSON metadata with commit SHA and build time
